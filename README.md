# Atlas Vault

Atlas's long-term memory, an Obsidian vault kept in this private GitHub repo.

- **Memory/**: lasting facts Atlas loads into every conversation (business, prices, policies, customers, people, preferences, ideas). Edit these freely; Atlas reads the latest version.
- **Jobs/**: one note per job, created by Atlas when you upload job-site photos, quotes or install docs.
- **Customers/**: one note per customer.
- **Daily/**: daily notes and wrap-ups.
- **Attachments/**: photos, video key frames, PDFs and files uploaded in Atlas chat, filed by month.
- **Templates/**: starting points for new notes.

How it syncs: Atlas writes here through GitHub. On your Mac, the Obsidian Git plugin pulls Atlas's changes and pushes yours. Every change is a commit, so nothing is ever truly lost.

Keep out of this vault: card numbers, bank details, passwords and ID numbers.
